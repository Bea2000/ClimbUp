# Estilo y Formato de Código

## General Code Style & Formatting
- Seguir el estilo de código de Airbnb (según las dependencias de ESLint en package.json).
- Usar PascalCase para los nombres de archivos de componentes React (ej. Navbar.tsx, Dashboard.tsx).
- Preferir exportaciones nombradas para componentes.
- Usar 'use client' en componentes que requieren interactividad del lado del cliente.

## Convenciones de Nombres
- El código debe estar en inglés (variables, funciones, comentarios).
- La interfaz de usuario debe estar en español (textos visibles al usuario).
